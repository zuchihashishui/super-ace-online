# Classic Royale artwork

Project asset: `client/assets/court-cards.png`.

Created using the built-in image generation tool for this project. The three equal panels contain original King, Queen and Jack illustrations. CSS selects each panel without adding image downloads per card; one asset is shared by the entire board. Generated image dimensions: 1536 × 1024.

Prompt:

> Use case: stylized-concept. Asset type: playing-card face artwork atlas for a web game. Create one landscape image, three EXACT equal width panels edge to edge, no gutters. Left panel: elegant classic king with gold crown, blue and burgundy robes, sword. Middle panel: elegant classic queen in red robes, gold crown, holding a flower. Right panel: classic jack in navy cap, blue and gold robes. Each figure is a waist-up front or slight profile portrait, centered within its own panel. Ivory background identical throughout. Crisp engraved black outlines with flat ivory, red, navy and gold inks, traditional French playing card aesthetic, beautifully detailed original illustrations. Figure fills each panel but leaves 10 percent safe margins. No text, no letters, no numerals, no suit symbols, no external border, no watermark. These will be used as three CSS background-position sprites; respect three equal vertical panels. Aspect ratio 3:2.

The uploaded screenshot is used as a visual reference for the cabinet palette and layout, not embedded as the game interface.
